📋 Daily Progress Report : LearnStream
Date: November 26, 2026 (Thursday)

🔎 Summary: The app stopped depending on local files. Its database moved from a SQLite file on the developer's machine to a hosted PostgreSQL service, and uploaded lesson videos and covers now go to Vercel Blob instead of a folder that disappears on deploy — while the rule that only signed-in members can watch a lesson is unchanged. The placeholder "LS" text in the header and footer was replaced with the new symbol logo, which also became the browser-tab icon, and refreshing a deep link such as `/browse` or `/watch/<id>` no longer shows a 404. An administrator sign-in was created and repaired on the hosted database so the catalog can be managed.

Detailed File Changes ᝰ✍🏻 .ᐟ

♻️ [UPDATED] | Uploads and media storage |
📁 File: `server/utils/storage.ts`, `server/api/videos/index.post.ts`, `server/routes/media/[...key].ts`, `.env.example`, `package.json`
- Uploaded videos and thumbnails are now stored in Vercel Blob when a Blob token is configured, and in the media folder otherwise, so a deployment keeps its media; deleting a lesson removes the file from whichever store holds it.
- `saveUpload` now receives the file's content type, so videos are stored as playable `video/mp4` instead of a generic binary type.
- `/media/<key>` still refuses videos to visitors who are not signed in and then forwards them to the file's Blob URL; thumbnails stay public and on-disk streaming is unchanged.
- Added the `@vercel/blob` dependency and documented the new token variable. Blob-hosted files use public links, so the members-only rule is enforced by keeping the link behind sign-in rather than by the store itself.

♻️ [UPDATED] | Branding |
📁 File: `src/components/AppHeader.vue`, `src/components/AppFooter.vue`, `index.html`, `src/assets/learnstream-logo.png`, `src/assets/learnstream-nav.png`, `src/assets/learnstream-icon.png`
- Replaced the letter-based "LS" mark and wordmark in the header and footer with the new symbol logo, and used a smaller variant as the browser-tab icon.
- Removed the now-unused `__mark` and `__wordmark` styles from both components.

♻️ [UPDATED] | Database and deployment |
📁 File: `prisma/schema.prisma`, `prisma.config.ts`, `server/utils/prisma.ts`, `prisma/seed.ts`, `prisma/migrations/20261126073604_init/migration.sql`, `nitro.config.ts`, `.env.example`, `.npmrc`, `.gitignore`
- The database moved from SQLite to Prisma Postgres: the datasource is now `postgresql`, the server connects through the `@prisma/adapter-pg` driver adapter using the pooled `DATABASE_URL`, and a new `prisma.config.ts` points the CLI at the direct `DIRECT_URL`.
- Added the first migration, `20261126073604_init`, and made the seed add only missing fixtures instead of clearing the tables first.
- Added a Vercel rewrite so browser-side routes fall back to `index.html` on a refresh, plus `.npmrc` for a flat `node_modules` and ignore rules for the `.vercel` output and `.env*` files.

📁 File: `.` (hosted database, no repository file)
